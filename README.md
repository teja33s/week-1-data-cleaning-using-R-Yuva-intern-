
# Data Cleaning and Preliminary Analysis with R

## Project Overview
This project performs data cleaning, preprocessing, and
exploratory data analysis on the publicly available Titanic
passenger dataset.

## Objectives
- Identify and handle missing values.
- Remove exact duplicate records.
- Detect outliers using the IQR method.
- Normalize numerical variables using Min-Max scaling.
- Encode categorical variables.
- Generate descriptive statistics and correlation analysis.
- Visualize passenger survival and age distributions.

## Technologies Used
- R Programming Language
- ggplot2
- dplyr
- tidyr
- corrplot

## Dataset
Titanic passenger dataset from the seaborn-data repository.

Source:
https://github.com/mwaskom/seaborn-data

## How to Run
1. Install R or RStudio.
2. Download or clone this repository.
3. Open data_cleaning_analysis.R.
4. Run the complete script.
5. Check the output folder for CSV files and charts.

## Outputs
The project generates a cleaned dataset, normalized data,
encoded data, descriptive statistics, an outlier summary,
a correlation matrix, and EDA visualizations.

## Key Findings
The analysis compares survival rates by passenger class
and sex and explores age, fare, and other numerical variables.
Actual findings should be documented after running the script.
